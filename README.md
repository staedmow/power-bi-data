# Аналитика продаж — Power BI отчёт

## 📌 О проекте
Данный репозиторий содержит выполненное тестовое задание (ТЗ) по аналитике продаж.  
Цель — построить интерактивный дашборд в Power BI на основе предоставленных данных, рассчитать ключевые метрики, провести ABC-анализ и выявить проблемные зоны (убыточные заказы, менеджеры с отрицательной прибылью).

**Файл отчёта:** `ТЗ_аналитика.pbix` (в корне репозитория).

## ✅ Что сделано (в соответствии с ТЗ)

### 1. Рассчитаны меры (DAX)
- Выручка
- Прибыль
- Рентабельность (с фильтрацией аномальных выбросов)
- АКБ (активная клиентская база)
- Средний чек
- Затраты на логистику
- Дополнительно: количество убыточных заказов и сумма убытка

### 2. Построены визуализации
- **Динамика показателей** (линейчатый график с вторичной осью для рентабельности)
- **Показатели по сегментам покупателей** (гистограмма)
- **Показатели по номенклатуре с drill-down** (матрица: Категория → Подкатегория → Продукт)
- **География продаж** (карта с использованием широты/долготы)
- **ABC-анализ номенклатуры** (таблица с группами A, B, C)
- **Менеджеры с убыточными заказами** (таблица с фильтрацией)

### 3. Модель данных
Построена по схеме «Звезда»:
- **Факт:** `Продажи`
- **Измерения:** `СПР_продукты`, `СПР_покупатели`, `СПР_Менеджеры`, `СПР_стоимость_доставки`
- **Календарь:** отдельная таблица дат, связанная с `СПР_даты_заказа`
- Все меры вынесены в отдельную таблицу `_Меры`

### 4. Подключение к источнику
Требование ТЗ: подключение только через Интернет.  
Исходный Excel-файл размещён в этом репозитории GitHub.  
В Power BI использован метод `Web.Contents` (ссылка на raw-файл GitHub).  
Тип подключения — **Импорт**.

## 🛠 Технологии
- Power BI Desktop
- Power Query (очистка, преобразование, создание ABC-анализа)
- DAX (меры, вычисляемые столбцы)

## 🚀 Как открыть и использовать
1. Скачайте файл `ТЗ_аналитика.pbix`.
2. Откройте его в **Power BI Desktop** (версия не ниже 2023 года).
3. При необходимости обновите данные: **«Главная» → «Обновить»**.  
   Для загрузки данных потребуется интернет-соединение (доступ к GitHub).
4. Все визуализации интерактивны: можно фильтровать по датам, сегментам, категориям.
